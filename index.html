Social Networking Engine

Vantage Point is a lightweight, full-featured social networking web application built with FastAPI, PostgreSQL, raw parameterized SQL queries, and server-rendered Jinja2 templates — no heavy ORM, minimal frontend overhead.

Key Capabilities & Features

Designed around direct database interactions and clean system architecture, with high-throughput, raw parameterized SQL executed directly against PostgreSQL.

Multi-Format Content Streams

Publish, index, and render text, high-resolution images, video, audio, documents, geolocated pins, and external link embeds.

Social Graph Architecture

User accounts, bidirectional follows, custom user groups, privacy blocking, and account-level permissions.

Interaction Engine

Fast processing for likes, nested comments, re-shares, custom bookmarks, and user mentions & hashtags.

Notification Pipeline

Event notifications for user activity, profile avatars, and email password resets via SMTP.

Zero-ORM Performance

All queries live as direct, optimized SQL in app/queries/ for predictable execution plans and minimal pool overhead.

Tech Stack & Architecture

A deliberately small stack: async Python on the server, PostgreSQL underneath, and server-rendered HTML on top.

Project Layout

Each domain gets its own module, its own SQL, and its own router.

app/
├── main.py            # FastAPI app setup, static mounts, router registration
├── config.py          # Environment settings (prefixed via VP_)
├── db.py              # PostgreSQL connection pool allocation
├── auth.py            # Password hashing, PBKDF2/argon2, session tokens
├── posts.py           # Feed aggregation, creation pipelines, listings
├── comments.py        # Threaded comment tree processing
├── likes.py           # Atomic like/reaction operations
├── shares.py          # Distribution and repost logic
├── notify.py          # Event notification handlers
├── settings.py        # Account privacy and blocklist controls
├── forgot_password.py # Secure token generation & SMTP handlers
├── avatar.py          # Multi-type media file storage & avatar pipeline
├── queries/           # Pure parameterized SQL statements per domain
├── routers/           # FastAPI route definitions (REST JSON API + HTML renderers)
├── schemas/           # Pydantic schema validation & data parsing
├── templates/         # Server-rendered Jinja2 templates
└── static/            # Native CSS and vanilla JS assets
migrations/            # Serialized raw SQL migration scripts
